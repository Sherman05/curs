# ИАС мониторинга успеваемости студентов с AI-модулем

Курсовая работа по направлению «Информационные системы и технологии».

Информационно-аналитическая система на Flask: мониторинг успеваемости,
AI-генерация учебных материалов (Anthropic Claude) и адаптивное обучение.

## Модули

1. **Аналитика успеваемости** — роли (студент/преподаватель/администратор),
   CRUD оценок/предметов/групп, дашборды с графиками, импорт CSV, экспорт PDF/Excel.
2. **AI-генератор учебных материалов** — генерация теории, конспектов, задач,
   контрольных и тестов с автопроверкой через Claude.
3. **Адаптивное обучение** — авто-генерация доп. задач студентам из группы риска
   (средний балл < 3.5).

## Технологии

- **Backend:** Flask, SQLAlchemy, Flask-Login, Flask-Migrate, SQLite
- **Frontend:** Bootstrap 5, Chart.js, Jinja2
- **AI:** Anthropic Claude (`claude-sonnet-4-5` / `claude-haiku-4-5`)
- **Аналитика/отчёты:** pandas, openpyxl (Excel), reportlab (PDF)

## Установка и запуск

```bash
# 1. Виртуальное окружение
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# 2. Зависимости
pip install -r requirements.txt

# 3. Настройки (опционально — для AI нужен ключ)
cp .env.example .env
# отредактируйте .env: задайте SECRET_KEY и ANTHROPIC_API_KEY

# 4. Создать БД и загрузить тестовые данные
flask --app app seed

# 5. Запуск
flask --app app run --debug
```

Приложение: http://127.0.0.1:5000

## Тестовые учётные записи

После `flask --app app seed` (пароль у всех — `password`):

| Роль          | Логин      |
|---------------|------------|
| Администратор | `admin`    |
| Преподаватель | `teacher1` … `teacher5` |
| Студент       | `student1` … `student30` |

## Миграции (альтернатива `seed`)

```bash
flask --app app db init      # один раз
flask --app app db migrate -m "init"
flask --app app db upgrade
```
